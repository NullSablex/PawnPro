# Suporte

## Antes de pedir ajuda

- Abra **`PawnPro: Ajuda e informações`** (paleta de comandos ou menu da status bar) para ver as versões dos componentes e links úteis.
- Verifique se o motor LSP está ativo: o item `PawnPro` na status bar deve estar visível.
- Confira os painéis de saída **PawnPro Engine**, **PawnPro Server** e **Pawn Build** para mensagens de erro.
- Para problemas difíceis de reproduzir, ligue o registro de diagnóstico (**PawnPro: Nível do diagnóstico**) e anexe o `.pawnpro/logs/pawnpro.log` — revise-o antes: ele pode conter caminhos do seu projeto.
- Certifique-se de que `.pawnpro/config.json` está configurado corretamente (ver [docs/configuration.md](docs/configuration.md)).
- Para dúvidas de depuração, consulte o [guia de depuração](docs/debugging.md).

## Canais de suporte

| Canal | Uso |
|-------|-----|
| [Issues do GitHub](https://github.com/NullSablex/PawnPro/issues) | Bugs, comportamento incorreto, sugestões e dúvidas de uso |

## Ao abrir uma issue de bug

Inclua:
- Versão da extensão (visível na status bar ou em Extensões → PawnPro)
- Sistema operacional e versão do VS Code
- Conteúdo relevante dos painéis de saída do PawnPro
- Passos mínimos para reproduzir o problema

## Vulnerabilidades de segurança

Não abra issues públicas para vulnerabilidades. Consulte [SECURITY.md](SECURITY.md).
